## 工作流程

1. 接收用户请求，创建书评
2. 使用 web_fetch 获取书籍信息（读书网、豆瓣、知乎等）
3. 创建 markdown 格式书评
4. 使用 pandoc + weasyprint 生成 PDF
5. git commit 提交
6. git push 推送到 GitHub 仓库

## 书评风格

每篇书评包含以下部分：

1. **书籍信息**：书名、作者、出版社、出版时间、评分等
2. **核心内容**：全书结构、核心观点、主要内容
3. **阅读体验**：适合读者、阅读方法、阅读建议
4. **评价与推荐**：优点、局限、推荐指数、适合读者
5. **结语**：总结书的价值和意义
